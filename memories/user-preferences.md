# Preferencias Inmutables del Usuario (User Preferences)
<!-- Registro de Restricciones y Deseos Explícitos del Usuario -->

1. **Precios Manuales como Núcleo Soberano**:
   - El usuario fija manualmente los precios de compra y venta de cada recurso.
   - Las consultas a APIs externas (Albion Data Project) son exclusivamente una ayuda referencial opcional. Prohibido sobreescribir datos locales sin la acción deliberada del usuario.

2. **Cero Tolerancia a la Invención de Mecánicas**:
   - En Albion Online no existen diarios de trabajadores para agricultura, herboristería ni cocina.
   - Los costes de las islas deben estar actualizados a las tarifas vigentes (post-Wild Blood).

3. **Metodología MoureDev como Forma de Trabajar**:
   - El usuario exige que el agente trabaje, razone y programe aplicando la metodología de MoureDev ("El nuevo programador", SDD, EARS, MCP, Harness, Constitución, Memorias, Multiagentes).
   - NO quiere pantallas didácticas o tutoriales dentro de la aplicación de Albion. La app debe permanecer limpia para el juego.

4. **Calidad Visual y Ergonomía Numérica**:
   - Fondo en escala de grises oscuros (`slate-950`).
   - Todos los números de plata, foco y costes deben usar fuente monoespaciada tabular (`tabular-nums`) y separador de miles.
